> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Çiftlerin magic link ile giriş yapabildiği, düğün oluşturup ikinci eşi davet edebildiği ve **hiçbir kullanıcının başka bir düğünün verisine erişemediği** bir kimlik/yetkilendirme katmanı kurmak.

**Tech Stack:** Express 4, Drizzle ORM, PostgreSQL 16, Zod, `jose` (JWT — pure JS, FreeBSD uyumlu), Brevo REST API, Vitest.

> **Neden `jose`, neden `jsonwebtoken` değil:** `jsonwebtoken` Node crypto'ya bağlı ve eski API; `jose` modern, Web Crypto tabanlı, ESM-native ve FreeBSD'de sorunsuz. Tek seçim: **`jose`**.

```ts
import { randomBytes, createHash, timingSafeEqual } from 'node:crypto'

/** Kriptografik rastgele token (base64url). Varsayılan 32 bayt = 256 bit. */
export function generateToken(bytes = 32): string {
  return randomBytes(bytes).toString('base64url')
}

/** Token'ı SHA-256 ile hash'ler. DB'de yalnızca bu saklanır. */
export function hashToken(raw: string): string {
  return createHash('sha256').update(raw, 'utf8').digest('hex')
}

/** 6 haneli yedek giriş kodu (kriptografik rastgele). */
export function generateShortCode(): string {
  const n = randomBytes(4).readUInt32BE(0) % 1_000_000
  return n.toString().padStart(6, '0')
}

/** Sabit zamanlı hash karşılaştırma — timing saldırısını önler. */
export function timingSafeEqualHex(a: string, b: string): boolean {
  if (a.length !== b.length) return false
  const bufA = Buffer.from(a, 'hex')
  const bufB = Buffer.from(b, 'hex')
  if (bufA.length !== bufB.length) return false
  return timingSafeEqual(bufA, bufB)
}
```
